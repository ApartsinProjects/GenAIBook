Part I

Orientation and Fast Start

This part fixes the "too abstract too early" problem. Readers see the whole pipeline first, then learn how to reason about tasks, metrics, and tools. The red thread is explicit from the beginning: synthetic data is created or repurposed in order to train, fine-tune, evaluate, and iteratively improve vision, audio, video, and multimodal models.

03

Task Taxonomy and Success Criteria

Turns fuzzy product ideas into tasks, labels, metrics, deployment constraints, and evaluation plans, including decisions about which model families will later be trained, fine-tuned, or benchmarked with synthetic data.

Core Undergraduate Graduate Engineering Research Companion Repo
Detailed Sections
  1. Vision tasks: classification, detection, segmentation, grounding, captioning, retrieval, VQA, and which are trained from scratch, fine-tuned from encoders, or adapted from foundation models.
  2. Audio tasks: ASR, diarization, event detection, keyword spotting, language ID, speaker tasks, and which benefit most from synthetic augmentation versus synthetic corpora.
  3. Video tasks: tracking, temporal localization, event recognition, captioning, and QA, with attention to temporal labels and fine-tuning requirements.
  4. Multimodal tasks: retrieval, report generation, operator copilots, incident understanding, and system-level evaluation with synthetic stress sets.
  5. Choosing evaluation metrics before collecting data.

The Modern Toolbox Without the Noise

Introduces the current tool ecosystem while separating durable workflow ideas from fast-changing package details, with explicit attention to tools for generating synthetic data, training and fine-tuning models, and evaluating them rigorously.

Core Undergraduate Graduate Engineering Research Companion Repo
Detailed Sections
  1. Core stack: PyTorch, torchvision, torchaudio.
  2. Hugging Face stack: transformers, diffusers, datasets, evaluate, peft, trl, accelerate.
  3. Modality tools: timm, kornia, open_clip, OpenCV, decord, PyAV, librosa, pyannote.audio, plus modality-specific generators, encoders, and task-model tooling for image, video, and audio.
  4. QA and labeling tools: FiftyOne, Label Studio, CVAT, Argilla, Distilabel, supervision, and SAHI-style slicing workflows.
  5. Experiment ops: DVC, MLflow, artifact stores, benchmark harnesses, contamination checks, memorization audits, W&B-style tracking, and calibration tooling.
  6. Deployment and export stack: ONNX Runtime, TensorRT, OpenVINO, Core ML paths, vector database or retrieval-store options, and observability or tracing hooks.

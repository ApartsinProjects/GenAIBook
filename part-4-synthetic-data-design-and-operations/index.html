This part is explicitly organized around the synthetic-data engine: choose a strategy, create or repurpose data, validate it operationally, and prepare clean inputs for later training and evaluation.

Designing the Synthetic Data Engine

Frames synthetic data as an iterative workflow rather than a generation event.

Detailed Sections
  1. Generated, augmented, repurposed, and hybrid strategies with explicit decision criteria for vision, audio, video, and multimodal tasks.
  2. Failure-slice discovery, coverage planning, taxonomy design, and curriculum-style data scheduling.
  3. When to use simulation, diffusion editing, weak-label repurposing, distillation-friendly pseudo-labeling, or full generation from scratch.
  4. Data economics: generation cost, reviewer cost, GPU-hours, storage, iteration-cycle time, and synthetic-to-real mixing policy.
Learning Outcomes
  • Design synthetic-data workflows as iterative systems rather than isolated prompts.
  • Choose between generation, editing, repurposing, and simulation.
  • Estimate the cost and value of synthetic-data campaigns.

Hands-On Track

  • Create a synthetic-data strategy memo for the case study.
  • Define failure slices and coverage targets.

Research Track

  • Turn the data strategy into a comparison study design.
  • Specify which strategy choices are experimental variables.
Key Tools, Libraries, and Models
  • Diffusers, simulation stacks, spreadsheet-style coverage planners, prompt matrices, DVC/MLflow runs, QA dashboards, data-mixture planning tables.
Representative Benchmarks and Datasets
  • Case-study slice tables, long-tail taxonomies, synthetic-vs-real benchmark manifests, and hidden failure-slice catalogs.
Suggested Notebooks and Demos
  • 14_synthetic-data-engine-planner.ipynb, 14_failure-slice-to-data-plan-demo

Image Data: Generation, Editing, and Repurposing

Covers prompt-driven generation, editing workflows, auto-labeling, and label-aware repurposing for image tasks.

Detailed Sections
  1. Text-to-image and latent diffusion pipelines for labeled sample generation using Stable Diffusion-class models, Flux-style pipelines, modular Diffusers workflows, and reusable generation graphs.
  2. Image editing workflows: inpainting, outpainting, image-to-image translation, relighting, style transfer, compositing, object insertion/removal, and DiffEdit-style editing with mask-aware pipelines.
  3. Control mechanisms: ControlNet, T2I-Adapter, masks, depth, canny, pose, segmentation maps, normal maps, layout conditioning, region-based prompts, IP-Adapter-style image control, and MultiAdapter composition.
  4. Personalization and concept control: textual inversion, DreamBooth-style tuning, LoRA adapters, adapter composition, and prompt token engineering.
  5. Negative prompts, prompt matrices, attribute coverage tables, seeded batch recipe design, style-diversity controls, image-reward filtering, and LCM-style fast-generation recipes for large-scale data synthesis.
  6. Repurposing real datasets through relabeling, weak supervision, editing, synthetic augmentation, and domain transfer.
What This Chapter Covers
  • Modern diffusion-based data generation and editing pipelines, not just basic prompting.
  • How to create controllable labeled examples with editing instead of always generating from scratch.
  • When textual inversion, LoRA, or ControlNet produce better synthetic training data than raw prompt engineering alone.
Learning Outcomes
  • Use diffusion pipelines for controllable synthetic image creation and editing.
  • Apply inpainting, image editing, ControlNet, and textual inversion to build labeled data.
  • Choose between raw prompting, editing, and personalization methods.

Hands-On Track

  • Build a reusable image recipe library with prompts, controls, and edit masks.
  • Run one comparison between prompt-only and ControlNet or edit-based generation.

Research Track

  • Measure how editing methods affect label fidelity and diversity.
  • Compare textual inversion or LoRA personalization against generic prompting.
Key Tools, Libraries, and Models
  • Diffusers, Stable Diffusion-class pipelines, Flux-style pipelines, modular diffusion pipelines, ControlNet, T2I-Adapter, MultiAdapter, inpainting models, IP-Adapter-style control modules, DiffEdit-style editing, textual inversion, DreamBooth-style tuning, LoRA adapters, LCM-LoRA-style acceleration, image reward models, kornia and OpenCV for mask prep.
Representative Benchmarks and Datasets
  • COCO, LVIS, synthetic prompt suites, internal attribute-coverage tables, and prompt-based challenge sets.
Suggested Notebooks and Demos
  • 15_diffusion-data-recipes.ipynb, 15_controlnet-inpainting-textual-inversion-demo

  3. Tracking, temporal grounding, segmentation propagation, interpolation-based annotation, SAM 2-style video tracking, event localization, tracker-assisted labeling, and reviewer correction loops for clip labeling.
  4. Temporal consistency, motion realism, annotation productivity, and video-specific failure buckets.
  5. Repurposing video via captioning, slicing, relabeling, and track correction.

Synthetic Data Operations: QA, Filtering, Reward Models, and Judge Loops

Focuses on operational QA after generation or repurposing so it does not blur together with the earlier chapter on annotation systems and auto-labeling.

Detailed Sections

  2. Judge models, confidence scoring, teacher-model review, rubric-based scoring, active error discovery, image-reward or preference-style ranking workflows, and acceptance-threshold tuning.
  3. Human review queues, adjudication, label repair, and escalation workflows.
  4. Bias checks, memorization checks, provenance validation, watermark verification where applicable, leakage checks, near-duplicate filtering with embedding or image-dedup tools, and calibration-aware filtering policies.
  5. Stopping criteria, iteration policies, and sample acceptance/rejection logging for generation campaigns.
What This Chapter Covers
  • How to prevent synthetic-data pipelines from becoming silent failure factories.
  • How to combine automatic judges and humans efficiently.

Learning Outcomes

  • Use judge models and human review coherently.

Hands-On Track

Research Track

Synthetic Data for Training, Evaluation, Stress Testing, and Challenge Sets

Separates three uses of synthetic data that are often conflated and need different design principles.

Detailed Sections
  1. Training data for coverage, balancing, sample-mixture scheduling, and teacher-student distillation workflows.
  2. Evaluation data for hidden slices, rare cases, contamination checks, memorization checks, and challenge-set construction.
  3. Stress tests for robustness, safety, failure analysis, distribution-shift probing, and abstention-policy testing.
  4. Why realism, calibration, uncertainty, and usefulness are not the same objective.
Learning Outcomes
  • Separate training, evaluation, and stress-test data design goals.
  • Use synthetic data to probe robustness and safety, not only improve training coverage.
  • Avoid conflating visual or acoustic realism with downstream usefulness.

Hands-On Track

  • Create one synthetic training set and one synthetic stress-test set.
  • Compare how each affects conclusions about model quality.

Research Track

  • Design an experiment that isolates usefulness from realism.
  • Build a hidden-slice benchmark with synthetic support data.
Key Tools, Libraries, and Models
  • Benchmark harnesses, hidden-test generators, challenge-set templates, stress-test templates, realism, calibration, uncertainty, abstention, and utility metrics.
Representative Benchmarks and Datasets
